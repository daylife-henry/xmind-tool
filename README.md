# MindMap Studio

一个开箱即用的网页版思维导图工具，定位是 **XMind 的轻量替代品 + 增强版**。不需要安装、不需要构建，双击 `index.html` 就能用。

---

## 已实现功能

### 核心编辑
- 节点增删改：子节点、兄弟节点、删除节点、双击/F2 编辑。
- 折叠/展开：点击节点旁的 `+` / `−` 图标，或用空格键切换。
- 多选布局：思维导图（向右）、组织结构图（向下）、径向图。
- 主题切换：彩色分支、暗色、简约三种主题。
- 自动布局：每次增删改后自动排版，连线使用平滑贝塞尔曲线。

### 导航与交互
- 画布平移：按住空白处拖拽。
- **节点拖拽**：直接按住任意节点拖动即可自由摆放，被拖节点的整棵子树会一起跟随移动；拖拽产生的位移会被记住，重新布局、切换主题、折叠展开都不会丢失，导出 SVG / JSON 也会保留。
- 缩放：鼠标滚轮以指针位置为中心缩放，或点击工具栏 `+` / `-`。
- 一键适配：自动把整张图缩放到窗口内。
- 方向键导航：支持上下左右在节点间跳转。
- 搜索高亮：顶部搜索框实时匹配并跳转到第一个结果。

### 导入导出
- 导出 JSON：把整棵思维导图保存为 `.json`，方便版本管理或再次编辑。
- 导入 JSON：打开之前保存的文件继续编辑。
- 导出 SVG：生成矢量图，可直接插入 PPT / 文档。

### 其他
- 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）。
- 内置示例：首次打开会加载一张“智能体”知识结构的示例导图。

## 快速开始

1. 直接用浏览器打开 `index.html`。
2. 点击节点选中，按 `Tab` 加子节点，`Enter` 加兄弟节点。
3. 双击节点或按 `F2` 改文字。
4. 工具栏可切换布局、主题、缩放、导入导出。

> 因为是纯静态页面，你也可以把它丢到任何静态托管服务（GitHub Pages、Cloudflare Pages、Nginx 等）上直接用。

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Tab` | 为选中节点添加子节点 |
| `Enter` | 为选中节点添加兄弟节点 |
| `Delete` / `Backspace` | 删除选中节点（根节点不可删） |
| `F2` / 双击 | 编辑节点文字 |
| `Space` | 折叠/展开子节点 |
| `↑ ↓ ← →` | 在节点间导航 |
| `Ctrl + S` | 导出 JSON |
| `Ctrl + O` | 导入 JSON |
| `Ctrl + E` | 导出 SVG |
| `Ctrl + N` | 新建空白导图 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 重做 |
| `+` / `-` | 放大 / 缩小 |

## 数据格式

导出的 JSON 是一棵递归的树：

```json
{
  "id": "node-1",
  "text": "中心主题",
  "collapsed": false,
  "color": null,
  "children": [
    {
      "id": "node-2",
      "text": "分支一",
      "collapsed": false,
      "color": "#6366f1",
      "children": []
    }
  ]
}
```

- `text`：节点文字。
- `collapsed`：是否折叠子节点。
- `color`：节点颜色（留空会自动按主题/分支分配）。
- `children`：子节点数组。

## 比 XMind 强在哪

这里说的是“同级别的轻量场景”，不是要和 XMind 的完整专业版硬刚：

1. **零依赖、零构建**：一个 HTML + CSS + JS 直接跑，不依赖 Electron、不打包。
2. **源码完全开放**：想要什么功能自己改，没有订阅墙。
3. **JSON 格式透明**：导图就是纯文本，可以版本控制、用脚本批量生成。
4. **三种布局一键切换**：XMind 免费版布局有限，这里内置了思维导图、组织结构图、径向图。
5. **SVG 矢量导出**：插入文档不会糊。
6. **搜索即达**：大导图里按方向键+搜索能快速定位。
